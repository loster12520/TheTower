## 简洁
- 以**最少文字**讲清楚**核心信息**。
- 删除不影响结论的赘述，避免“先说很多再进入主题”。

## 强调
- 每段约 200 字，只强调**首句或尾句**的**关键词**。
- **加粗**用于名词；<u>下划线</u>用于动词；每次强调仅用 1 次下划线与 1~2 次加粗。
- 中文段落**禁止斜体**；斜体仅用于英文书名或论文名。

## 举例
- 示例必须使用引用或代码块包裹，读者会跳读示例。
- 示例中可使用**更明确的强调**与**注释**，但不滥用。

> ✅ 示例（引用版）：
> - 目标：让读者最快找到**关键动作**。
> - 方法：<u>突出</u>“提交”“删除”等动词，并**只强调一次**。

```
// ✅ 示例（代码块版）
// 说明：强调关键动作，不堆叠强调
执行流程：先<u>校验</u>，再**提交**。
```

## 文本规范
- 能用单行代码就用单行代码，例如：`POST /api/v1/login`。
- 有对比或盘点时优先使用表格。
- 标题从一级开始，逐级递减。
- 需要顺序或计数时使用有序列表；否则使用无序列表。
- 可删而不影响逻辑但有助理解的文字，用引用标记为补充说明。

## 导语与总结
- 每篇文档必须有导语与总结，**各用一句话**。
- 导语说明目的；总结回顾主要部分。
- 当结构复杂（标题超过两层或二级标题 ≥ 5 个）时，在导语后增加可跳转目录。

总结：以上规范覆盖简洁、强调、举例、文本规范与导语总结，写作前先遵守即可。
