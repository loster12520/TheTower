# TheTower 未完成项清单（0.1.0 收口后）

导语：本文档仅保留 0.1.0 收口后仍需在后续版本继续推进的事项，已完成首版闭环的能力不再列入缺口。

## 1. 当前缺口总览

| 主线 | 缺口 | 优先级 |
|---|---|---|
| 协作能力深化 | 细粒度自动合并策略、冲突状态机可视化 | P1 |
| 权限模型深化 | 从“模板级分享”扩展到更细粒度操作授权 | P1 |
| 高级调试完善 | 条件断点与时间旅行的端到端自动化覆盖进一步增强 | P1 |
| 运维与审计 | 调度、会话、协作链路的审计与运维文档增强 | P2 |
| 持久化演进 | 文件存储与 SQLite 的并发与恢复能力增强 | P2 |

## 2. 已从缺口清单移除的条目

以下条目已在 0.1.0 完成首版闭环，不应继续作为“未完成”出现。

- 自动保存、模板搜索、标签/分组、模板克隆、自动布局、批量删除、运行参数面板。
- 条件断点、时间旅行、调试预览远程操控。
- `saveData`、`saveExcel`、`importExcel`、`getClipboardText`、`extractActiveElement`。
- `listenRequestTrigger`、`listenRequestResult`、`stopPageListen`。
- 调度任务、模板市场、认证与工作空间、协作编辑首版。

## 3. 后续优先级建议

1. 先做协作与权限深化，因为这两条直接影响多人场景稳定性。
2. 再补高级调试自动化覆盖，提升复杂问题定位效率。
3. 最后推进运维审计与持久化演进，强化部署质量。

总结：0.1.0 之后的工作重点已经从“功能有没有”转向“协作与运维能力做得够不够稳”。
