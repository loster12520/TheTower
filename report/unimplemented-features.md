## 五、优先级建议

### 高优先级（建议近期实现）
1. **keyboardPress / keyboardHotkey** - 基础交互能力，使用频率高
2. **textExtract** - 数据处理基础能力，配套 convertJson/extractKey/randomGet

### 中优先级（功能完善）
3. **saveData / saveExcel / importExcel** - 文件数据持久化
4. **getClipboardText / extractActiveElement** - 便捷数据获取
5. **closeOtherPages / goBack** - 页面流完整操作

### 低优先级（复杂集成）
6. **googleSheet** - 需要 OAuth 凭证体系
7. **getEmail** - 需要邮件协议支持
8. **listenRequestTrigger / listenRequestResult** - 网络拦截复杂度高
9. **预览画面远程操控** - 需要坐标映射与输入转发
