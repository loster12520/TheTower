## 7. 缺陷闭环

| 缺陷ID | 场景 | 现象 | 原因 | 修复 | 结论 |
|---|---|---|---|---|---|
| BUG-901 | WebSocket 心跳验证 | 脚本初版未命中 `PONG` | 服务端只识别 JSON `{"type":"PING"}`，不响应纯文本 `PING` | 修正脚本与文档口径，统一改为 JSON 心跳 | 已闭环 |
| BUG-902 | Edge 浏览器兼容 | `edge` 实际错误映射到 `webkit` | 浏览器解析逻辑未区分 Edge channel | 后端改为 Chromium `msedge` channel，并补浏览器映射单测 | 已闭环 |
| BUG-903 | 50 节点性能用例 | 拖拽测量早期不稳定或被工具栏遮挡 | React Flow 自动化拖拽坐标与目标区域选择不准确 | 调整节点选择、画布定位与鼠标拖拽路径，真实性能用例稳定通过 | 已闭环 |
