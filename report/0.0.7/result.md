# TheTower 0.0.7 版本总结

导语：本文档用于 0.0.7 收官时汇总目标达成情况、统一测试结果、关键缺陷修复与发布结论。

## 1. 版本目标与达成情况

| 目标项 | 状态 | 结果说明 |
|---|---|---|
| 调试控制深化 | 已完成 | 已交付断点、暂停、继续、单步与变量快照，并补齐真实联调覆盖。 |
| 流程复用 | 已完成 | `callWorkflow` 已支持参数映射、结果写回、循环引用校验与真实回归。 |
| 数据处理步骤 | 已完成 | `convertJson`、`extractKey`、`randomGet` 已接入前后端并通过真实执行验证。 |
| 0.0.6 不回归 | 已完成 | 预览、全屏、宿主机浏览器调试入口与编辑器体验继续稳定。 |

## 2. 统一测试与质量结果

- 后端打包：`backend/gradle buildFatJar` 通过。
- 前端构建：`frontend/yarn build` 通过。
- 前端 mock 回归：`21/21` 通过。
- 前端真实联调：`12/12` 通过。
- 新增 0.0.7 真实能力覆盖：断点暂停、单步、继续、数据步骤真实执行、`callWorkflow` 参数映射与结果写回全部通过。

## 3. 关键缺陷修复

- 修复：数据步骤表单保存字段与后端真实执行字段不一致，导致 0.0.7 新步骤只能“看起来能配”，不能稳定运行。
- 修复：调试快照中的 `variables` 缺省时，变量检查器会直接崩溃。
- 修复：`callWorkflow.inputMapping` 对纯变量名不兼容，子流程入参会收到字面量而不是父流程变量值。
- 修复：真实联调用例中的重复文本断言冲突，收敛为更稳定的精确匹配。

## 4. 发布结论

- 0.0.7 已达到版本计划中的交付目标，可作为当前主线发布基线。
- 本版已经把 0.0.6 的“可预览”推进到 0.0.7 的“可暂停、可恢复、可复用、可处理数据”。
- 未纳入的条件断点、表达式断点和远程接管仍保持为后续版本规划项，不构成 0.0.7 未完成项。

总结：0.0.7 的收官结论应以“调试能停能继续、流程能复用、数据能闭环、旧能力不回归”的统一自动化结果为准。
