# TheTower 0.1.0 技术实现报告

导语：本文档用于记录 0.1.0 围绕全量能力补完、调试增强、外部集成和产品化首版所做的技术实现工作，作为测试报告与版本总结的技术依据。

## 1. 版本定位

- 0.0.9 已完成本地交付闭环、指标验收与部署文档沉淀。
- 0.1.0 的目标转为清空当前未完成清单，并形成产品化初版。

## 2. 本版技术主线

| 主线 | 说明 | 当前状态 |
|---|---|---|
| 云部署实机验收 | 完成真实云环境部署、运行与问题闭环 | 待开始 |
| 编辑器体验增强 | 自动保存、搜索、标签、克隆、自动布局、批量删除、运行参数面板 | 已完成首版 |
| 高级调试 | 条件断点、时间旅行、远程操控 | 已完成首版 |
| 数据与文件集成 | 文件、Excel、剪贴板、焦点元素节点 | 已完成首批节点 |
| 网络与第三方平台 | 请求监听、Google Sheet、邮箱、验证码平台、LLM | 请求监听首版已完成 |
| 产品化能力 | 调度、模板市场、权限、多租户、协作编辑 | 模板市场首版、调度首版与权限协作含在线 presence、保存级远端同步、多人冲突差异详情、本地定位、远端节点只读预览、远端节点与连线选择性采纳的首版已完成 |

## 3. 已完成工作

- 已完成 `plan/0.1.0/plan.md`，冻结版本目标、范围、风险与完成判定。
- 已完成 `plan/0.1.0/requirements.md`，冻结全部需求与验收口径。
- 已完成 `plan/0.1.0/steps/api.md`、`backend-plan.md`、`frontend-plan.md`，作为实现前置拆分文档。
- 已完成 `report/0.1.0/test.md` 初始模板，用于后续逐项回填测试结果。
- 已完成模板管理增强首版：模板搜索、模板克隆、批量删除、标签与分组、首页筛选与展示。
- 已完成编辑器增强首版：自动保存、自动布局、运行参数面板统一普通运行与调试运行的启动参数。
- 已完成高级调试首版：条件断点、时间旅行调试、调试预览远程点击与远程输入。
- 已完成数据与文件集成首批节点：`saveData`、`saveExcel`、`importExcel`、`getClipboardText`、`extractActiveElement`。
- 已完成请求监听首批节点：`listenRequestTrigger`、`listenRequestResult`、`stopPageListen`，支持当前页请求/响应摘要监听、结果读取与显式解绑。
- 已完成模板市场首版：后端新增 `/api/v1/market/templates` 的列表、发布与导入接口，前端首页新增模板市场 Drawer 与卡片级“发布到市场”入口，当前数据通过独立文件仓储落盘，不改动现有模板主表。
- 已完成调度首版最小闭环：后端新增 `/api/v1/schedules` 的列表、创建、更新、删除接口与后台轮询触发，当前支持 `ONE_TIME` 与 `INTERVAL` 两种触发方式，调度数据通过独立文件仓储 `data/schedules/schedules.json` 落盘，并复用 `RunService.startRun(...)` 触发运行；前端首页新增调度任务 Drawer、卡片级“创建调度”入口，可查看最近触发时间、最近运行状态并执行启停与删除。
- 已完成权限协作首版最小闭环：后端新增 `POST /api/v1/auth/login`、`POST /api/v1/auth/logout`、`GET /api/v1/me`、`GET /api/v1/workspaces` 与模板协作接口 `GET /api/v1/templates/{id}/collaboration`、`POST /api/v1/templates/{id}/collaboration/share`，会话数据走独立文件仓储 `data/auth/sessions.json`，模板访问边界与分享关系走 `data/collaboration/templates.json`；前端首页新增“账户权限”Drawer 与模板卡片“协作设置”入口，可登录演示账号、切换工作空间并分享模板给协作者。
- 已完成在线协作 presence 首版：后端新增 `GET /api/v1/templates/{id}/collaboration/presence`、`POST /api/v1/templates/{id}/collaboration/presence/heartbeat`、`DELETE /api/v1/templates/{id}/collaboration/presence` 与 `WS /ws/v1/templates/{templateId}/collaboration`，基于内存 presence service 维护当前模板在线成员；前端编辑器工具栏新增在线协作者状态条，优先消费 WebSocket 事件，连接失败时退回轮询兜底；mock 与真实后端均已验证双页面共享模板时在线人数与成员姓名变化。
- 已完成协作保存级远端同步首版：后端在 `PUT /api/v1/templates/{id}` 成功后广播 `COLLABORATION_PATCH_APPLIED`，并把最新 patch 元数据并入 presence 快照；前端编辑器协作 store 统一处理 WebSocket patch 事件、presence 中的 `latestPatch` 与模板 `updatedAt` 轮询兜底，在本地无脏数据时自动 `loadTemplate(...)` 刷新，存在未保存改动时展示“远端模板已更新”提示；mock 与真实后端双页签回归均已验证 Bob 保存后 Alice 会自动看到新增节点。
- 已完成协作冲突提示首版：前端编辑器在在线协作者数量大于 1 时暂停自动保存，避免本地改动在多人协作场景下抢先覆盖远端；当 `remotePatch + isDirty` 同时成立时，工具栏显示“协作冲突”状态，页面展示冲突 Alert，并提供“丢弃并同步”与“覆盖保存”两个显式动作；mock 与真实后端均已验证 Alice 本地未保存改动与 Bob 远端保存并存时会稳定进入冲突态。
- 已完成协作冲突差异摘要首版：前端新增 `frontend/src/utils/collaborationDiff.ts`，基于“本地已保存快照 vs 当前画布”和“本地已保存快照 vs 远端模板详情”分别计算轻量增删改摘要；冲突 Alert 会同时展示“本地变更 / 远端变更”两行摘要，帮助用户在覆盖保存与丢弃同步前快速判断影响范围；mock 与真实后端冲突回归均已验证差异摘要可见。
- 已完成协作冲突差异详情首版：前端冲突 Alert 新增“查看差异详情”入口，点击后弹出详情 Modal，分别展示本地与远端的新增节点、删除节点、修改节点和连线变化，避免用户只看一行摘要就做决策；对应 mock 与真实后端冲突回归均已验证详情弹窗可见。
- 已完成本地差异节点定位首版：差异详情中的本地新增/修改节点改为可点击的“定位到节点”按钮，点击后会关闭详情弹窗并重新选中对应画布节点，缩短“看到差异 -> 回画布检查”的路径；对应 mock 与真实后端冲突回归均已验证点击后可重新打开该节点配置面板。
- 已完成远端差异节点只读预览首版：差异详情中的远端新增/修改节点改为可点击的“预览远端节点”按钮，点击后会打开只读预览弹窗，展示远端节点类型、画布坐标与配置 JSON，帮助用户在不覆盖本地改动的前提下判断远端保存内容；对应 mock 与真实后端冲突回归均已验证预览弹窗可见。
- 已完成远端节点选择性采纳首版：协作 store 在拉取远端差异时同时缓存远端根节点与关联连线，差异详情中的远端新增/修改节点新增“采纳远端节点”按钮；点击后会把目标节点及当前可落地的关联连线并入本地主画布，同时保留当前冲突上下文，方便用户继续决定是否保存合并结果；对应 mock 与真实后端冲突回归均已验证采纳后本地节点数增加且远端节点出现在画布中。
- 已完成远端删除节点选择性采纳首版：差异详情中的远端删除节点新增“采纳远端删除”按钮，点击后会直接从本地主画布移除对应节点与关联连线，同时继续保留当前冲突上下文，方便用户后续决定是否保存整版；对应 mock 与真实后端删除冲突回归均已验证采纳后本地画布节点数降为 0。
- 已完成远端新增连线选择性采纳首版：`frontend/src/utils/collaborationDiff.ts` 已把连线差异从数量摘要扩展为可枚举的新增/删除连线明细，协作 store 可缓存远端边并提供边级 merge payload，差异详情弹窗新增“采纳远端新增连线”按钮；点击后会把远端边直接并入本地主画布，同时继续保留当前冲突上下文。由于 0.0.x 编辑器仍有单入边/单出边限制，前端回归通过测试注入远端 patch 的方式验证边级采纳链路，mock 与真实后端用例均已通过。
- 已完成远端删除连线选择性采纳首版：编辑器 store 新增按 edgeId 删除本地主画布连线的原子动作，差异详情弹窗中的远端删除连线会渲染“采纳远端删除连线”按钮；点击后会把目标连线从本地冲突画布中移除，同时继续保留当前冲突上下文。由于正常编辑器 UI 仍限制线性流程，mock 与真实后端回归同样通过测试注入远端 patch 的方式验证删边采纳链路。
- 已完成冲突采纳后的远端差异自动收缩首版：协作 store 现会保留一份原始远端差异，并在节点/连线采纳后基于当前本地画布重算“剩余未解决的远端差异”，避免已采纳项继续停留在冲突摘要和详情里，同时不把本地脏改动误计入远端变更；当前 mock 与真实后端已用远端删节点、增边、删边回归验证该收缩逻辑。
- 已完成远端差异清零后的冲突态自动退出首版：当剩余未解决的远端差异收缩为 0 时，协作 store 会直接清理当前 `remotePatch` 与冲突上下文，让工具栏冲突状态、页面冲突 Alert 与差异摘要一并退出，避免用户在所有远端差异都已处理完成后继续停留在空冲突态；mock 与真实后端已用远端删节点、增边、删边采纳回归验证冲突提示会自动消失。
- 已完成冲突详情连续采纳收口首版：差异详情弹窗在用户采纳单个远端节点或连线后，不再无条件关闭，而是继续保留未解决项并提示“已解决项已隐藏”；只有当剩余远端差异收缩为 0 时，弹窗才会随冲突态一起退出，缩短“逐项采纳多个远端变更”的操作路径；当前 mock 与真实后端均已补回归验证“先采纳远端修改节点，再继续采纳远端新增节点”的连续处理链路。
- 已完成冲突解决后的本地合并待保存提示首版：当远端差异已经全部处理完成，但本地合并结果尚未保存时，协作 store 会保留一份“已解决远端冲突”的短生命周期上下文；页面工具栏会显示“合并结果待保存”Tag，并在画布区展示独立 Alert，引导用户保存当前合并结果，而不是退回到普通未保存态中丢失协作语义；当前 mock 与真实后端已补连续采纳回归，验证该提示会在保存成功后自动清除。
- 已完成远端差异处理建议首版：差异详情弹窗现会根据远端差异类型给出优先级建议，当存在远端删除节点/连线时提示优先处理删除项；当远端以修改项为主时提示先确认远端修改；仅在主要为新增项时才提示可按需逐项采纳，减少用户在复杂冲突场景下自行判断处理顺序的成本；当前 mock 与真实后端已分别补删除节点、远端修改伴随新增连线的回归验证。
- 已完成当前批次验证：前端 `npm run build` 通过；后端 `TemplateServiceTest`、`TemplateMarketServiceTest`、`SchedulerServiceTest`、`AuthServiceTest`、`TemplateCollaborationServiceTest`、`TemplatePresenceServiceTest`、`StepTreeSupportTest`、`DebugExecutionGateTest`、`PlaywrightRunExecutorTest` 已按主线分批通过；前端 `frontend/e2e/regression.spec.ts` 与 `frontend/e2e/real-backend.spec.ts` 已补模板市场、调度、权限协作、在线 presence、请求监听、文件与 Excel、焦点元素、剪贴板节点回归并通过。
- 已完成真实联调稳定性修正：`frontend/playwright.real.config.ts` 改为优先复用现有 8011 dev server，降低 Umi `.umi` 临时目录生成抖动导致的 Playwright 启动早退风险；当前真实后端协作冲突详情用例已在新配置下重新通过。

## 6. 风险与约束

- 0.1.0 范围较大，必须按 steps 文档分主线推进，避免一次性混改。
- 高级调试与协作能力涉及前后端状态同步，需优先冻结协议与状态机。
- 第三方平台与调度能力需要 mock 或降级策略，避免测试完全依赖外部环境。
