# TheTower 用户使用手册（0.1.0）

导语：本文档面向首次使用 TheTower 的用户，说明从启动系统到模板协作的完整操作路径。

## 1. 启动系统

### 1.1 启动后端

```powershell
cd backend
.\gradlew.bat run
```

### 1.2 启动前端

```powershell
cd frontend
npm install
npm run dev
```

### 1.3 健康检查

```powershell
Invoke-RestMethod http://127.0.0.1:8080/api/v1/health
```

## 2. 模板管理

1. 在首页点击“新建模板”。
2. 输入名称和描述，进入编辑器。
3. 通过搜索框按关键字过滤模板。
4. 使用标签/分组筛选模板。
5. 通过卡片操作可克隆或批量删除模板。

## 3. 编辑器编排

- 左侧：步骤库。
- 中间：画布。
- 右侧：节点配置或运行面板。

常用流程：

```text
拖拽节点 -> 连接节点 -> 配置参数 -> 保存模板 -> 运行/调试
```

## 4. 体验增强能力

- 自动保存：编辑期间自动写回，减少手动保存频率。
- 自动布局：快速整理画布节点位置。
- 运行参数面板：运行前可设置浏览器、超时、headless 等参数。

## 5. 运行与调试

### 5.1 普通运行

1. 点击“运行”。
2. 查看运行状态、输出摘要、日志与产物。

### 5.2 调试运行

1. 点击“调试运行”。
2. 使用继续、单步等控制。
3. 通过预览区查看执行画面。
4. 支持条件断点、时间旅行和远程操控首版能力。

## 6. 数据与网络监听节点

- 文件与 Excel：`saveData`、`saveExcel`、`importExcel`。
- 运行期数据：`getClipboardText`、`extractActiveElement`。
- 网络监听：`listenRequestTrigger`、`listenRequestResult`、`stopPageListen`。

## 7. 产品化入口

### 7.1 模板市场

- 打开首页“模板市场”抽屉。
- 支持浏览、发布和导入模板。

### 7.2 调度任务

- 打开首页“调度任务”抽屉。
- 支持创建单次或间隔任务，并查看最近触发结果。

### 7.3 账户权限

- 打开首页“账户权限”抽屉登录。
- 可查看当前用户并切换工作空间。

### 7.4 协作编辑

- 在模板卡片打开“协作设置”分享模板。
- 编辑器可查看在线成员、远端更新提示与冲突差异详情。

## 8. 常见排查

1. 运行失败时先看失败节点和日志。
2. 调试异常优先检查断点条件与当前调试上下文。
3. 协作冲突优先看差异详情，再决定采纳远端或覆盖保存。
4. 若联调异常，先确认后端地址、token 和工作空间头是否正确。

总结：0.1.0 的推荐使用路径是“模板管理 -> 编辑编排 -> 运行调试 -> 市场/调度/协作”，按此顺序可覆盖绝大多数场景。
