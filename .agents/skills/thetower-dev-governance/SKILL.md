# thetower-dev-governance

导语：本 Skill 用于统一 TheTower 的“先文档后开发”流程、变更边界约束、命名与注释规范，以及前后端文件职责地图，确保多轮迭代可持续且可验收。

## Skills 索引
1. [skills/development-process.md](skills/development-process.md) - 版本开发流程与质量门禁规范
2. [skills/file-responsibility-map.md](skills/file-responsibility-map.md) - 前后端目录职责与命名约束地图

## 使用建议
- 当任务涉及“新版本启动、跨模块重构、流程资产交付、代码治理”时优先使用本 Skill。
- 当任务仅涉及文档排版规范时，配合 `lignting-document` Skill 使用。

总结：本 Skill 是 TheTower 0.0.2 起的项目级工程治理底座，目标是让流程、质量与代码职责可以被检查和复用。
