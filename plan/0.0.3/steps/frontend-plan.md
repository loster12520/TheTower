# 0.0.3 前端实施文档（模板导入/导出）

导语：前端在不新增页面的前提下，把首页现有的“导入模板/导出”入口从占位变为可用功能。

## 1. 导入实现
- 首页“导入模板”按钮触发文件选择。
- 读取 JSON 后做最小校验并调用后端：创建模板 -> 保存 steps。

## 2. 导出实现
- 首页模板卡片“更多 -> 导出”：拉取模板详情并下载 JSON。

## 3. 交互与提示
- 导入成功：提示成功并刷新列表。
- 导入失败：提示失败原因（解析失败/版本不支持/字段缺失/接口错误）。
- 导出失败：提示接口错误。

## 4. 回归清单
- 导出一个模板并导入回来，步骤数一致。
- 导入后进入编辑页，画布节点可见且可保存。

总结：前端 0.0.3 以“模板交换可落地”为核心，避免引入额外交互复杂度。
