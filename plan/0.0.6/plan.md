# 0.0.6 版本目标（运行调试可视化 + 画布编辑体验重构）

导语：本版本聚焦把 0.0.5 的“可运行”升级为“可调试、可高效编辑、可稳定测试”的体验闭环，优先交付近实时预览、全屏调试、左右端口、无抖动选中态与编辑器快捷操作。

## 1. 版本目标

| 目标项 | 优先级 | 说明 | 验收信号 |
|---|---:|---|---|
| 运行调试可视化 | P0 | 运行时可看到近实时浏览器画面，并能全屏查看 | 运行面板出现调试预览，预览可放大 |
| 宿主机调试入口 | P0 | 调试模式可打开可见浏览器与 DevTools | 调试入口可触发宿主机浏览器调试窗口 |
| 画布连接体验重构 | P0 | 节点改为左右端口，自动连线吸附更符合横向流程 | 节点连线方向统一，50px 内可自动吸附 |
| 画布视觉稳定性 | P0 | 选中节点不再因边框变宽导致抖动 | 选中与取消选中时节点位置稳定 |
| 编辑效率提升 | P0 | 支持复制、剪切、粘贴、撤销、重做 | 常见快捷键与菜单操作可用 |
| 0.0.5 不回归 | P0 | 保持 outputs/artifacts、失败定位、作者流和真实联调稳定 | 0.0.5 核心用例继续通过 |

## 2. 版本边界（不做）

- 不在本版继续扩充新的步骤家族，如 `callWorkflow`、数据处理四件套、第三方工具步骤。
- 不在本版承诺“预览画面内直接点击接管浏览器”的远程操控能力。
- 不做跨模板系统级剪贴板同步与多人协作编辑。
- 不做自动排版、连线中插入节点、智能布线等更重的画布智能化能力。

## 3. 核心方案摘要

### 3.1 调试方案

- 在现有 run 事件之外新增调试通道，用于推送近实时预览帧、当前 `pageAlias`、`contextId` 与调试状态。
- 0.0.6 第一阶段只做**只读预览**，不在前端直接发送鼠标键盘接管指令。
- 调试模式允许后端以可见浏览器方式启动，并提供宿主机 DevTools 打开入口。

### 3.2 画布方案

- 所有节点 Handle 统一从上下改为左右，匹配横向流程编排。
- 选中态不再通过 `borderWidth` 变化表达，改为固定边框宽度加颜色或阴影变化。
- 编辑器增加复制、剪切、粘贴、撤销、重做，以及短阈值自动连线。

### 3.3 测试方案

- 本版测试优先级与实现优先级一致，不再把体验验证留到收尾。
- 前端 Playwright 要覆盖节点交互与调试预览；后端黑盒要覆盖 debug session、frame push 与 DevTools 控制接口。
- 回归测试必须同时覆盖 0.0.5 的默认运行模式，确保调试功能不会拖慢或破坏正常运行。

## 4. 分阶段推进

### Phase A：文档与协议定义（P0）

- 完成 `plan/0.0.6/plan.md`
- 完成 `plan/0.0.6/requirements.md`
- 完成 `plan/0.0.6/steps/{api.md,backend-plan.md,frontend-plan.md}`
- 完成 `report/0.0.6/{tech.md,test.md}` 模板

### Phase B：后端调试会话与协议（P0）

- 新增调试会话生命周期
- 定义调试帧事件、调试状态与控制接口
- 支持非 headless 启动与 DevTools 打开

### Phase C：前端运行预览与全屏调试（P0）

- 扩展运行面板为“监控 + 预览”双层结构
- 增加全屏预览、当前页面标签、上下文标签
- 增加调试模式状态与错误提示

### Phase D：画布连接与节点视觉重构（P0）

- 节点 Handle 从上下改为左右
- 修复选中态抖动
- 调整 minimap、连线方向与容器节点摘要展示

### Phase E：编辑效率功能（P0）

- 复制、剪切、粘贴
- 撤销、重做
- 自动连线阈值吸附

### Phase F：测试与回归（P0）

- 后端调试黑盒
- 前端 mock 与真实联调 Playwright
- 0.0.5 默认运行链路回归
- 性能与稳定性回归

## 5. 主要风险

| 风险 | 影响 | 缓解策略 |
|---|---|---|
| 高频截图推送拖慢运行链路 | 预览卡顿，后端 CPU 升高 | 调试模式下限流，设置帧率上限与质量上限 |
| 可见浏览器与 DevTools 只适合本地环境 | 服务器场景无法复用 | 文档中明确“本地调试模式”边界 |
| 历史栈与剪贴板实现不当 | 画布状态错乱、子流程污染 | 先限定当前画布作用域，节点与边粘贴统一重生成 ID |
| 自动连线吸附绕过线性流程约束 | 产生非法边 | 自动吸附继续复用现有单入单出校验 |
| 左右端口改动影响已有节点样式 | 真实联调和缩略预览错位 | 节点、容器节点、minimap 与子流程预览统一联调验证 |

## 7. 版本完成判定

1. 调试模式可显示近实时浏览器画面，且可全屏查看。
2. 调试模式可打开宿主机浏览器与 DevTools。
3. 节点端口改为左右布局，选中时无抖动。
4. 复制、剪切、粘贴、撤销、重做可在当前画布作用域稳定使用。
5. 自动连线在约 50px 阈值内可吸附，且不破坏单入单出约束。
6. 0.0.5 的 outputs/artifacts、失败定位、作者流与真实联调不回归。

总结：0.0.6 的重点不是继续堆功能点，而是把运行调试与画布编辑体验从“能用”提升到“顺手、可观测、可验证”。
