## 范围与非目标

- 范围：运行时支持近实时浏览器画面预览、全屏查看和宿主机 DevTools 打开入口。
- 范围：画布节点端口统一改为左右布局，并修复选中节点边框抖动。
- 范围：编辑器支持复制、剪切、粘贴、撤销、重做和短阈值自动连线。
- 范围：本版测试重点转向体验专项，要求 mock、真实联调与黑盒验证同步跟进。
- 非目标：不在本版继续扩充新步骤家族。
- 非目标：不做预览画面中的远程点击与输入接管。
- 非目标：不做跨模板系统级剪贴板同步与多人协作。

## 承接基线（来自 0.0.5）

- 0.0.5 已完成：outputs、artifacts、pageAlias、contextId 的最小可观测运行链路。
- 0.0.5 已完成：运行面板、失败定位、真实联调、多标签页与浏览器上下文基础能力。
- 0.0.6 不重做运行主链路，而是在此基础上补齐**调试可视化**与**编辑效率**。

> 说明：0.0.6 的核心不是“新增几个按钮”，而是让**运行可观察、编辑可恢复、连接更顺手**，并且把这些体验点做成可测试能力。

## 0.0.6 运行调试体验

### 1. 近实时浏览器预览

- 调试模式下，运行面板应显示当前浏览器页面的近实时图像。
- 本版允许采用“截图帧推送”方式实现，只要求**近实时**，不要求视频级流畅。
- 推荐约束：默认帧率 2 到 4 fps，可在后端做节流。
- 默认运行模式不应开启帧推送，避免影响普通执行性能。

### 2. 全屏预览与信息面板

- 调试预览必须提供“全屏查看”入口。
- 全屏状态下至少展示：
  - 当前运行状态
  - 当前 `pageAlias`
  - 当前 `contextId`
  - 最近步骤路径
- 全屏关闭后，运行面板状态应保持，不重新建立 run。

### 3. 宿主机浏览器与 DevTools

- 调试模式允许后端以可见浏览器方式启动。
- 前端应有明确入口触发“打开宿主机浏览器/DevTools”。
- 本版只承诺本地开发环境可用，不要求服务器部署场景支持。
- 若宿主机环境无法打开可见浏览器，应返回明确错误提示，而不是静默失败。

### 4. 调试状态与默认运行隔离

- 调试模式与默认运行模式要明确区分。
- 默认模式继续沿用 0.0.5 的执行方式，不额外推送帧。
- 调试模式失败时，不影响 run 的基本状态回传与错误定位。
- 调试模式关闭后，应释放预览通道与相关缓存，避免内存堆积。

## 0.0.6 画布编辑体验

### 1. 左右端口与横向连线

- 所有节点输入端口在左侧，输出端口在右侧。
- 容器节点与普通节点保持统一端口方向。
- 连线样式应与横向流向一致，不允许出现默认上下布局遗留。

### 2. 选中态无抖动

- 选中节点时允许出现更强视觉高亮，但不允许因 `borderWidth` 变化导致布局偏移。
- 推荐做法：固定边框宽度，改用颜色、阴影或 outline 表达选中状态。
- 容器节点与普通节点都必须满足该要求。

### 3. 复制剪切粘贴

- 支持当前画布作用域内的复制、剪切、粘贴。
- 粘贴时必须重生成节点与边 ID，避免与原图冲突。
- 粘贴结果应默认带少量位置偏移，避免完全重叠。
- 本版先不承诺跨模板粘贴与系统剪贴板富文本兼容。

### 4. 撤销与重做

- 至少支持当前画布作用域的撤销与重做。
- 建议覆盖的操作：
  - 添加节点
  - 删除节点
  - 移动节点
  - 更新节点配置
  - 添加或删除连线
  - 粘贴与剪切
- 撤销后再进行新操作，应截断未来历史分支。

### 5. 自动连线阈值吸附

- 当两个节点的端口足够靠近时，允许自动形成连线。
- 初始阈值按 50px 左右实现，并在真实联调中观察是否需要微调。
- 自动连线仍需服从现有流程限制，如单入单出、自环禁止。
- 若靠近多个候选端口，应选择最近且合法的一条边。

## 前后端实现约束

### 前端约束

- 调试预览优先在现有 `RunPanel` 基础上增强，不额外造第二套运行页。
- 画布快捷键应与主流编辑器习惯一致，优先支持 Ctrl 或 Cmd 组合键。
- 左右端口改造后，节点摘要、子流程预览、minimap 与连线样式要同步验证。

### 后端约束

- 调试模式与默认执行模式必须共享同一套 run 生命周期，不允许形成两套运行语义。
- 预览帧推送必须可控、可限流、可关闭。
- 打开宿主机浏览器与 DevTools 的接口必须有明确错误返回与日志。

### 协议约束

- 调试事件建议新增独立事件类型或独立调试通道，不直接污染 0.0.5 的普通运行事件消费逻辑。
- 运行结果与事件的既有字段保持兼容，不替换 `stepPath`、`outputs`、`artifacts`。

## 测试与验收口径

1. 调试预览闭环
   - 启动调试模式并运行模板。
   - 验收点：运行面板出现预览画面，画面持续更新，当前页面与上下文信息可见。

2. 全屏调试闭环
   - 在运行中点击全屏按钮。
   - 验收点：进入全屏后仍持续更新，退出全屏不丢失运行状态。

3. DevTools 闭环
   - 在本地调试模式下点击“打开浏览器调试”。
   - 验收点：宿主机可见浏览器开启，DevTools 打开或有明确失败提示。

4. 画布交互闭环
   - 添加两个节点并连接。
   - 验收点：端口位于左右，选中节点时无抖动，靠近时可自动吸附连线。

5. 编辑操作闭环
   - 复制一个节点并粘贴，再执行剪切、撤销、重做。
   - 验收点：节点与连线状态正确恢复，ID 不冲突，位置有偏移。

6. 回归闭环
   - 运行 0.0.5 真实联调与 mock 回归。
   - 验收点：outputs/artifacts、失败定位、作者流、多标签页与浏览器上下文不回归。

## 延期项（明确不纳入 0.0.6）

| 类别 | 延期项 | 延期原因 |
|---|---|---|
| 远程调试 | 预览画面内直接点击或输入接管 | 坐标映射、输入转发与安全边界复杂度高 |
| 画布智能化 | 自动排版、拖入连线自动插入节点 | 与当前体验目标相比优先级较低 |
| 剪贴板增强 | 跨模板粘贴、系统级富剪贴板同步 | 需要更重的跨作用域设计 |
| 新步骤扩展 | `callWorkflow`、数据处理四件套、第三方工具 | 与本版体验主线无关 |

总结：0.0.6 的交付标准是“运行时可看、调试时可放大、编辑时更顺手、回归时不退化”，先把体验主链路做透，再考虑更重的远程操控与智能化能力。
